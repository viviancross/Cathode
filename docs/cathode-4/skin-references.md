# Skin references (Cathode 4)

What the real boxes did, gathered from their user manuals and period reviews.
Skins evoke these boxes; they ship no brand names, logos, or proprietary fonts.

Visual specifics (exact colors, type, spacing) still need period screenshots,
to be collected when each skin is built. Behavior below is from the manuals.

## InDirect (DirecTV-style)

### SD variant: D10 / D11 / R15 (2004-2006)

- The D10 was the first receiver with only the provider's own interface; that
  interface stayed on SD receivers for years. R15 (2005) was the first DVR on it.
- **Channel banner**: date, time, channel, message inbox, parental-control
  state, current program title and times. Medium and large sizes; RIGHT grows
  it (small > medium > large), UP/DOWN move between its icons. Icons are bright
  when active (alternate audio, new messages) and dim otherwise. Lock icon has
  three states: locked, temporarily unlocked, unlocked.
- **Guide**: 14 days of listings, a picture window showing the live channel
  while browsing, category sort, "Find By" search. RECORD in the guide sets a
  one-touch recording.
- **Mini guide**: on a color key (BLUE) while watching; scroll channels/times
  without leaving the picture.
- **MENU opens the Quick Menu**: Settings, Audio Options, Category Sort, Pay Per
  View, Find By, Date & Time, Favorites, Caller ID & Messages, Parental Controls.
  Settings has Satellite (signal strength / dish alignment), Access Card,
  Setup, Reset, Scheduler.
- **LIST = Playlist** with a disk-space bar (blue = keep until deleted, light
  blue = will expire, black = free).
- EXIT returns to live TV. ENTER tunes a typed channel at once.
- Live buffer: pause, rewind, FF, instant replay, a control bar with a marker.
- Front panel: a ring of twelve blue lights shows state (an idle animation idea).

### HD variant: HR20 (late 2006 on)

- Replaced the TiVo-based DVR's interface with the provider's own; reviewers
  called it slick but less intuitive.
- Guide is grid-only, six rows, with an animation when paging channels.
- GUIDE first opens a filter menu; a second GUIDE shows the grid.
- Same family of keys: MENU, GUIDE, LIST, EXIT, BACK, PREV, ACTIVE, color keys.

## Plate (Dish-style)

### SD variant: 301 / 322 / DishPVR 508 / 522

- **Main Menu** items are numbered and pickable by digit: MENU then 1 opens the
  Program Guide.
- **Browse banner**: RIGHT (labeled BROWSE) then UP/DOWN flips through other
  channels' programs at the bottom of the screen while the current channel
  keeps playing. VIEW TV clears it.
- **Guide**: every channel, including unsubscribed ones, which show with a red
  background. SELECT on a program tunes it.

### HD variant: ViP622 / 722 (2006 on)

- Guide default layout puts live video in the upper right; it can expand to
  3 hours x 7 channels. Another layout is text only at regular size. One review
  saw about four channels at a time in one-hour steps.
- Time, date, and channel number always sit top left.
- Guide shows the active Favorites list: All Chan, All Sub, All HD, plus user
  lists. GUIDE cycles lists.
- **Main Menu**: Program Guide, Themes & Search, Customer Support, Multimedia,
  Locks, System Setup, Daily Schedule, Preferences.
- **Themes & Search**: browse by theme (News/Business, Family/Kids, Music/Arts,
  Sports, Movies) and sub-theme; search title/person/description with an
  on-screen keyboard or texting-style number pad.
- **Browse**: current program at the top, a list of other programs bottom-left.
- SELECT on a program opens a sub-menu of watch / record modes.
- BACK reverses at 4x, 15x, 60x, 300x on successive presses.
- Lists: My Recordings, Timers (shows why a timer was skipped).
- VIEW LIVE TV returns to live TV.

## Mapping to Cathode features

| Box concept | Cathode 4 |
|---|---|
| Channel banner, sizes / INFO | Banner on every tune; INFO expands |
| Browse banner | Browse (other channels' programs, no tune) |
| Mini guide / color key | Mini-guide |
| Themes / Category Sort | Genre "themes" button |
| Pay Per View / On Demand | Plex (On Demand / PPV) |
| Playlist / My Recordings | DVR downloads (My Recordings) |
| Satellite signal / dish alignment | Diagnostics "signal meter" |
| Live buffer + control bar | Pause live TV + rewind |
| Quick Menu / numbered Main Menu | Box menu tree, per skin |
